# Field-specific acquisition plan

The field-specific target is **at least 10,000 validated unique arrangements per field**, without an upper cap.

Initial fields:

1. Orchestra / symphonic / chamber orchestra
2. Band / pop-rock / worship / CCM ensemble
3. Jazz / big band / combo
4. Choral / vocal ensemble
5. General multi-instrument

The current 17,599-row exact-pair artifact belongs only to field 5 until field classifiers and manual QA establish otherwise. Source-reported corpus sizes are discovery counts, not accepted counts.
