# Band score–audio catalog scope

This catalog treats a score/audio pair as exact only when the PDF, compressed MusicXML and MIDI originate from the same PDMX source score and the audio is rendered deterministically from that exact MIDI. It does not claim identity with a separate commercial or human performance.

Band classes are reported separately: modern rhythm band, big band or jazz ensemble, concert or wind band, brass band, marching or pep band, and broad band ensemble. Strict and broad counts must not be merged silently.

PDMX license fields are preserved as provenance metadata, but uploader-provided labels are not independent copyright clearance. The catalog references official source paths instead of redistributing source binaries.
