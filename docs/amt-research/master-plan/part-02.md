# 7. TPCR 공통 정의와 금지사항

Target-Preserving Context Replacement


T는 곡 A의 모든 대상 bass stem의 합, CA는 A의 비타깃 반주, CB는 다른 곡 B의 비타깃 반주다. 첫 실험의 B는 한 곡이며, 여러 곡의 악기별 혼합은 C03에서 따로 시험한다. [S2 §5,26]


```text
정상 입력:      xA = h × (T + CA)
반주 교체 입력: xB = h × (T + g × CB)
동일 타깃 성분: h × T
동일 정답:      yT

타깃만 입력:    h × T            → 정답 yT
반주만 입력:    h × CA 또는 h×g×CB → 정답 빈 타깃
```


g는 donor context를 맞추는 gain이고 h는 쌍 전체에 공통으로 적용한다. 원곡과 교체곡을 각각 normalize하거나 각각 limiter에 통과시키면 타깃 waveform 동일성이 깨질 수 있다. 공통 headroom은 두 후보 peak를 함께 고려해 정한다.


| 통제 | 기록·분기 |
| --- | --- |
| TCR | bass가 활성인 구간의 타깃/반주 에너지 비를 비교한다. 빈 타깃이면 비율이 정의되지 않으므로 별도 negative 계층으로 처리한다. |
| 저역·밀도 | 저역 간섭, 활성 stem 수, onset 밀도, polyphony, time-frequency 겹침을 기록한다. |
| donor | 동일 split, 원곡/근접 중복 제외, GM 32–39 제거, 43·저음 비타깃은 별도 flag로 기록한다. |
| 음악성 | 타깃–반주 정합성과 donor 반주 내부 정합성을 구별한다. 다른 곡 전체 반주는 내부적으로 음악일 수 있다. |
| 후처리 | 비선형 compression/distortion의 실사용 증강은 A05로 분리한다. target-preserving 기전 분석에 섞지 않는다. |



**정답이 같아도 관측 난이도는 같지 않다. 반주 교체 후 F1 변화만으로 “음악적 shortcut이 증명됐다”고 결론내리지 않는다. 매칭 후에도 잔여 masking·음색·정보 손실이 존재할 수 있다.**


> M2의 50:50은 정상 샘플 절반을 “교체”하는 설계다. 반주 데이터를 추가한 효과와 구분하려면 C02의 repeat/remix 대조가 필요하다.

## 반주 변경에 따른 성능 저하와 예측 흔들림


```text
CIPD_i = F1(y_i, p_i,orig) − mean_k F1(y_i, p_i,cf,k)
CPD_i  = 1 − mean_k NoteF1(p_i,orig, p_i,cf,k)
F1micro = 2ΣTP / (2ΣTP + ΣFP + ΣFN)
```


CIPD는 교체 전후 정답 성능의 차이, CPD는 예측끼리의 차이다. 둘 다 낮으면서 모든 조건에서 틀릴 수 있으므로 조건별 절대 F1·음표 수·빈 출력률을 함께 본다. 예측 두 집합이 모두 비면 CPD 항을 임의의 성공으로 계산하지 않고 NA 비율과 공통 비어있음 비율을 따로 기록한다.


> 중앙 5초에서는 중심 창 안에서 시작한 참조/예측 note를 기본 onset 평가 대상으로 소유시킨다. 이전부터 이어진 sustain은 별도 frame/tie 검사로 둔다. Offset 평가에 필요한 문맥 밖 종료는 우측 검열 여부를 보고한다. [방법론 정교화]

# 9. 결과 판정 체계

개선·동등·악화·불확정을 섞지 않는다


각 비교에는 사전에 실용적 효과 기준 δ를 정한다. 예: F1 점수 0–100 척도에서 0.5 또는 1.0점은 내부 screening 후보이지 학계 표준이 아니다. 데이터 규모와 실제 편집 비용에 맞춰 등록한다. 모델 결과를 보고 유리한 기준으로 바꾸지 않는다.


| 기호 | 정의 | 다음 행동 |
| --- | --- | --- |
| + | 개선 방향과 크기가 사전 기준을 만족한다. 확증에서는 CI가 +δ보다 위다. | 재현 후 확대한다. |
| 0 | 동등 범위 안이라는 근거가 있다. 확증에서는 CI 전체가 [−δ,+δ] 안이다. | 더 싼/단순한 방법을 선택한다. |
| − | 악화 방향과 크기가 사전 기준을 만족한다. 확증에서는 CI가 −δ보다 아래다. | recipe를 수정하거나 우회한다. |
| ? | 표본·반복이 부족하거나 CI가 경계를 가로질러 판정되지 않는다. | 불확정으로 남기고 확인한다. |



p값이 유의하지 않다는 이유만으로 0을 주지 않는다. 1 seed의 CI는 평가곡 불확실성만 반영하므로 네 기호도 “pilot 신호”로 읽는다. 입력/지표/학습 검증이 실패한 경우는 ?가 아니라 “무효 실행”으로 분리한다.


## 첫 실험의 세 독립 비교


```text
dC = F1(C1) − F1(M0)  : 일반 추가학습
 dS = F1(M1) − F1(C1)  : 베이스 전용 목적
 dT = F1(M2) − F1(M1)  : TPCR 교체

실용 베이스 이득 = dC + dS
최종 M2 이득     = dC + dS + dT
```


다음 네 페이지는 dC/dS/dT 각각 {+,0,−,?}의 4³=64가지 판정 조합을 전부 등록한다. 부호만으로 혼합된 합의 최종 부호를 정할 수 없으므로 M1−M0, M2−M0도 직접 계산한다. CI는 같은 곡을 재표본화해 비교값 자체로 계산한다.


**실제음악 F1이 좋아졌는데 CPD가 줄지 않아도 실용 성과는 남는다. 다만 “문맥 의존 감소가 원인”이라는 기전 주장은 지지되지 않는다. 성능 가설과 기전 가설을 별도 판정한다.**
