예를 들어 타깃 6종×크기 3종×갱신 4종×반주 6종×비율 5종×자료 4종×loss 3종×seed 3종만 교차해도 77,760회 학습 후보가 된다. 이 계산은 격자의 크기를 보이는 예시이며 실제 실행 계획이 아니다.


| 단계 | 무엇을 고정하고 무엇을 바꾸나 | 통과 후 |
| --- | --- | --- |
| P0 | 정답·코드·지표·비용을 검사한다. | EXP01로 간다. |
| P1 screening | Bass+Small+기본 CE에서 M0/C1/M1/M2를 비교한다. | 가장 유망한 비교 1–2개를 선택한다. |
| P2 원인 분리 | 비율·일반 리믹스·일관성·실제자료 등 한 축씩 바꾼다. | 필요한 상호작용만 검사한다. |
| P2 확인 | 다른 seed, 다른 악기 또는 다른 자료에서 핵심 비교를 반복한다. | 효과 범위를 좁혀 확정한다. |
| P3 확대 | Medium/Large·복수 독립 전문가·통합 시스템을 평가한다. | 잠근 실제음악 test를 실행한다. |



## 우선 검사할 상호작용


전문화×TPCR, TPCR×일관성, 합성/실제자료×갱신 범위, 음원 분리×학습 입력, 무규칙 비율×교육 순서, 전문가 정보×오류율, 모델 크기×자료량, 선택적 출력×전체 recall을 우선한다. 나머지 조합은 큰 주효과 또는 실패 신호가 있을 때 추가한다.


## 실행 불가·의미 없음 조합도 기록한다


타깃을 바꾸고 정답은 고정한 쌍, test stem을 train donor로 사용한 조합, 미주석 악기를 없음으로 취급하는 전체 악기 loss, 정답 stem 없이 측정 불가능한 oracle 입력, 베이스 토큰에 드럼 오프셋을 강제하는 조합, 조건을 주지 않는 모델에 CFG를 임의로 추가하는 조합은 제외 사유를 명시한다.


> 독립 변수 하나만 바꾸는 실험을 우선하되, 강한 상호작용이 예상되는 경우에는 2×2 요인 설계로 함께 확인한다. 탐색 실험과 사전 등록한 확증 실험을 같은 증거 수준으로 취급하지 않는다.
