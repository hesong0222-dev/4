**비교 설계** 베이스 다음 피아노 또는 기타 한 종류에서 같은 대조군을 재현하고, 이후 나머지로 확장한다.

**통제** 악기마다 정답 범위·음역·드럼 클래스와 오프셋 정의를 먼저 고정한다.

**판정·다음** 악기별 효과가 다르면 하나의 보편적 주장 대신 악기별 조건을 보고한다.


## S03 패밀리 대 세부 악기

**가설** 베이스 패밀리 하나보다 핑거·피크·슬랩 등 세부 전문가가 유리한가?

**비교 설계** 패밀리 독립 모델과 세부 악기별 독립 모델을 비교한다. 세부 레이블이 확인된 자료만 사용한다.

**통제** MuScriptor 기존 그룹과 실제 주법 레이블을 혼동하지 않는다. 같은 총 데이터·모델 비용을 병기한다.

**판정·다음** 세분화가 유리하고 실사용 분류가 가능할 때만 별도 체크포인트를 늘린다.


## S04 처음부터 학습 대 사전학습 전환

**가설** 특정 악기만 처음부터 학습하는 것보다 범용 지식에서 시작하는 편이 유리한가?

**비교 설계** 무작위 초기화 전문가·범용 체크포인트에서 전환한 전문가·원본 모델을 비교한다.

**통제** 작은 후속학습 예산에서 처음부터 학습한 모델이 불리한 것은 예상 가능한 예산 효과로 분리한다.

**판정·다음** 저예산 효율과 충분히 수렴한 성능을 구분하며, 재학습은 추가 자원 확보 후 수행한다.

## S05 독주 대 혼합음 학습

**가설** 독립 전문가라도 혼합음을 듣는 연습이 필요한가?

**비교 설계** 타깃 독주만·정상 혼합음만·두 입력의 혼합으로 학습한 독립 모델을 모두 실제 혼합음에서 평가한다.

**판정·다음** 독주 점수만 개선되면 배포 목표 달성으로 보지 않고 혼합음 비중을 높인다.


## S06 전문화 대 타깃 학습 비중

**가설** 효과가 독립 가중치 때문인가, 베이스에 주는 학습 비중 때문인가?

**비교 설계** 전체 악기 추가학습·베이스 가중 추가학습·악기 부분집합 요청 학습·베이스 전용 학습을 비교한다.

**통제** 출력 조건과 베이스 정답 노출량을 맞춘 추가 대조군을 둔다. 독립 구조의 인과적 우월성으로 과장하지 않는다.

**판정·다음** 타깃 가중치만으로 같은 이득이면 기여를 학습 배분 효과로 좁혀 설명한다.


## S07 장르 전문화

**가설** 악기 전문화 안에서 장르별로 더 나누면 정확도가 오르는가?

**비교 설계** 하나의 베이스 모델과 팝·재즈·록 등 장르별 독립 베이스 모델을 장르 내·장르 밖에서 비교한다.

**통제** 곡·아티스트 중복을 차단하며 장르 분류 오류와 전문가 수 증가 비용을 포함한다.

**판정·다음** 장르 밖 손실이 크면 장르를 고정 분기하지 않고 다양한 정상음악으로 단일 전문가를 유지한다.


## S08 악기별 다른 구조

**가설** 각 악기에서 서로 다른 구조를 쓰는 것이 동일 MuScriptor 복제보다 유리한가?

**비교 설계** 토큰 생성형·프레임 예측형·전용 음높이/시작 검출형의 독립 모델을 악기별로 비교한다.

**통제** 같은 평가셋·전처리·허용 정보로 비교하고 모델별 사전학습 자료와 연산량을 공개한다.

**판정·다음** 정상음악 검증 성능으로 악기별 후보를 정하고 B01의 독립 모델 묶음으로 연결한다.

**가설** 전체 가중치를 바꾸는 것과 뒤쪽 층만 바꾸는 것 중 무엇이 좋은가?

## F02 LoRA·adapter·prompt

**가설** 작은 추가 파라미터만 학습해도 독립 전문가의 성능을 얻는가?

**비교 설계** LoRA rank 4/8/16/32·adapter·soft prompt를 전체 갱신 기준과 비교한다. QLoRA는 별도 호환성 검증 후 후보로 둔다.

**통제** 최종 전문가는 각자 별도 체크포인트로 저장한다. 공유 backbone의 동적 MoE를 제안하는 실험이 아니다.

**판정·다음** 품질/비용이 개선될 때 채택하고, 장착 전후 초기 출력 일치와 병합 후 일치를 검증한다.


## F03 학습률과 중단 시점

**가설** 기존 능력을 손상시키지 않는 학습 강도가 있는가?

**비교 설계** 초기 후보 3e-6·1e-5, 1천·2천·3천 업데이트를 비교하고 필요할 때 범위를 넓힌다.

**통제** 탐색 횟수를 사전 제한하고 test로 고르지 않는다. 스케줄 총길이 변경을 단순 resume로 처리하지 않는다.

**판정·다음** 실제음악 검증이 하락하면 조기 중단·더 작은 학습률을 먼저 검토한다.


## F04 샘플·토큰·이벤트 손실

**가설** 짧은 무음 정답도 충분히 학습시키는 손실 정규화가 무엇인가?

**비교 설계** 전체 토큰 평균·샘플별 토큰 평균·시작/종료/음높이 이벤트 가중 CE를 비교한다. focal/label smoothing은 후속 후보이다.

**통제** 다른 가중치는 새로운 학습 목적임을 명시하고 C1/M1/M2에 동일한 비교 규칙을 적용한다.

**판정·다음** 정상 F1과 무음 FP를 함께 개선할 때 채택한다. CE 감소만으로 선택하지 않는다.

**비교 설계** 정상 replay 없음/있음, 합성·실제 replay 비율을 바꿔 비교한다.

**가설** 원본 예측이나 가중치에서 너무 멀어지지 않게 하면 망각이 줄어드는가?

**판정·다음** 정상음악 향상이 억제되면 규제를 약화하거나 신뢰 가능한 샘플에만 사용한다.


## F07 출발 체크포인트 단계

**가설** 실제음악/RL까지 학습한 모델에 합성 CE를 다시 주는 것이 불리한가?

**비교 설계** 동일 크기의 synthetic·real-SFT·최종 체크포인트가 확보되는 경우에만 동일 후속학습을 비교한다.

**통제** 공개되지 않은 중간 가중치를 있는 것으로 가정하지 않는다. 자료가 없으면 최종 체크포인트 연구로 한정한다.

**판정·다음** 모든 추가학습 모델이 악화되면 출발 단계·도메인 망각을 우선 가설로 남긴다.


## F08 평가지표 지향 후학습

**가설** CE 이후 음표 단위 점수를 직접 최적화하면 실제음악이 더 좋아지는가?

**비교 설계** 안정적인 SFT 모델에 시퀀스 위험 최소화 또는 F1 보상 기반 RL을 별도 단계로 적용한다.

**통제** 동일한 고품질 정답으로 추가 SFT한 대조군을 두며 보상 계산·샘플링 비용을 포함한다.

**판정·다음** 온셋만 올리고 길이·FP를 악화시키는 보상 해킹을 배제한 뒤 고비용 단계로 확대한다.

**가설** 정상 샘플 일부를 다른 곡 반주로 교체하는 것이 유리한가?

**비교 설계** TPCR 비율 0/10/25/50/75/100% 후보 중 0·50%를 먼저 비교한다.

**통제** 총 타깃 노출을 맞춘 replacement 실험이다. 100%는 극단 비교이지 기본 추천이 아니다.

## C02 반복·일반 리믹스 대조군

**가설** 반주 교체가 단순 반복·gain 증강보다 특별한 이득을 주는가?

**비교 설계** N normal+N repeat, N normal+N 원곡 리믹스, N normal+N TPCR을 비교한다.

**통제** 같은 타깃 ID·노출 횟수·전체 샘플 수와 gain 분포를 맞춘다.

**판정·다음** TPCR만 개선되면 교체 특이적 근거가 생기지만 음악적 shortcut의 완전한 증명은 아니다.


## C03 한 곡 반주 대 여러 곡 반주

**가설** 반주 내부의 음악성까지 깨는 것이 추가 도움이 되는가?

**비교 설계** 한 donor 곡의 비타깃 전체 반주와 악기마다 다른 곡에서 가져온 반주를 비교한다.

**통제** 활성 악기 수·음량·밀도를 맞추고 타깃과 반주의 관계, 반주 내부 관계를 구분한다.

**판정·다음** 여러 곡 혼합이 실제음악을 악화시키면 한 donor 설계를 유지한다.


## C04 화성만 변화

**가설** 다른 악기의 음높이 관계를 깨면 타깃 인식이 달라지는가?

**비교 설계** 반주 전체 조옮김·반주 음높이 순열·독립 음높이 생성 조건을 분리한다.

**통제** 조옮김은 반주 내부 화성을 보존한다. 렌더링/피치변환 인공음과 저역 masking도 측정한다.

**판정·다음** 화성 조작 효과는 음향 변화를 동반한다는 한계를 붙여 해석한다.

**통제** 경계 절단·클릭·겹침 변화와 onset 밀도를 기록하고 길이 변형 여부를 분리한다.

**판정·다음** 그루브 의존과 단순 transient 간섭을 분리할 다음 대조군을 선택한다.


## C06 반주 종류별 영향

**가설** 어떤 주변 악기가 특정 타깃의 오인식에 가장 큰 영향을 주는가?

**비교 설계** 드럼만·피아노만·기타만·모든 비타깃 악기를 교체하거나 제거한다.

**통제** 타깃 제거 실험과 context 제거 실험은 다른 것이다. 제거 시 정답 변경 여부를 명시한다.

**판정·다음** 악기쌍별 간섭 지도를 만들고 X 계열의 명시적 전문가 협력으로 연결한다.


## C07 음향 난이도 matching

**가설** TPCR의 이득이 더 쉬운 음향을 만들었기 때문인가?

**비교 설계** 무매칭·RMS/TCR 매칭·저역/밀도 추가 매칭·엄격 매칭을 비교한다.

**통제** 매칭 통과율과 버려진 샘플의 편향도 보고한다. 완벽한 음향 동등성을 주장하지 않는다.

**판정·다음** 이득이 매칭 후 사라지면 음악적 효과보다 난이도 분포 변화로 해석한다.


## C08 타깃 제거·타깃만 진단

**가설** 모델이 반주만으로 없는 타깃 음을 생성하는가?

**비교 설계** 같은 묶음에서 T+CA, T+gCB, T만, CA만, CB만을 고정된 gain으로 평가한다.

**통제** 반주만 조건의 정답은 빈 타깃이다. 저음 비타깃을 베이스로 착각하는 단순 악기 오분류도 분리한다.

**판정·다음** context-only FP 감소와 실제음악 F1을 함께 확인하며 단독으로 인과 증명하지 않는다.

## R01 타깃×반주 2×2

**가설** 타깃과 반주의 음악성을 각각 깨는 효과가 다른가?

**비교 설계** 타깃 정상/랜덤 × 반주 정상/랜덤의 네 조건을 동일 렌더러에서 비교한다.

**통제** 타깃을 랜덤화하면 정답 MIDI도 바꾼다. 동일 정답을 강제하는 TPCR 쌍과 혼동하지 않는다.

**판정·다음** 정상 타깃+랜덤 반주가 유리한지, 전체 랜덤도 필요한지 가설을 분리한다.


## R02 연주 가능한 랜덤 대 제한 없는 랜덤

**가설** 물리적으로 가능한 무규칙 데이터가 더 좋은가?

**비교 설계** 음역·동시발음·주법을 제한한 랜덤과 제한 없는 독립 랜덤을 비교한다.

**통제** 음표 수·길이·세기 분포를 가능하면 맞추고 실제 불가능 조합은 스트레스셋으로 별도 표시한다.

**판정·다음** 실제음악 이득이 없는 극단 랜덤은 학습 기본값에서 제외한다.


## R03 무엇을 무작위화할 것인가

**가설** 음높이·시작·길이·세기 중 어떤 변수가 효과를 만드는가?

**비교 설계** pitch, onset, duration, velocity를 하나씩 바꾼 네 조건과 주요 두 변수 조합을 비교한다.

**통제** velocity 조작은 렌더링 변수이다. 출력 토큰이 0/1이면 표현적 velocity 예측 성과라고 하지 않는다.

**판정·다음** 효과가 있는 변수만 후속 혼합 실험에 남긴다.


## R04 랜덤 데이터 비율

**가설** 무규칙 예제가 많아질수록 정상 성능은 어떻게 변하는가?

**비교 설계** 0/5/10/25/50/100% 비율의 후보를 순차 탐색한다.

**통제** 학습 분량·렌더러·타깃 난이도를 맞추고 정상/랜덤 검증을 분리한다.

**판정·다음** 정상 F1이 최대인 비율을 우선하며 OOD 전용 최적값은 보조 결과로 둔다.
