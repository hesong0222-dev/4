# RWC Classical orchestral MIDI–audio alignments

This directory enumerates the **10 orchestral entries** in the RWC Classical Music Database:

- 4 symphony movements
- 2 concerto movements
- 4 other orchestral works

Each row identifies the Tokyo City Philharmonic Orchestra recording, the reference MIDI duration, the published MIDI–audio synchronization products, and the source access restrictions.

## Boundary

SyncRWC alignment is automatic and the upstream site explicitly warns that it is not ground truth and may contain errors. No manual postprocessing was applied. The records are therefore classified as `human_orchestra_midi_audio_automatically_aligned`, not as exact printed-edition matches. Full files are restricted to authorized RWC users and are not mirrored here.
