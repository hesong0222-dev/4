# Mutopia Orchestra score–MIDI manifest

This directory enumerates every record returned by Mutopia Project's `Instrument=Orchestra` listing as inspected on **2026-08-28**.

## Result

- Records: **67**
- Unique Mutopia IDs: **67**
- Exactness tier: `same_symbolic_source_exact`
- Score source: LilyPond
- Associated outputs: MIDI and PDF
- Human-performance claim: **none**

Each row points to its individual Mutopia detail page. That page exposes the LilyPond source and the associated MIDI/PDF outputs for the same typeset edition. A work split into movements or numbers remains split because Mutopia publishes those records separately.

## Files

- `manifest.csv` — item-level metadata, instrumentation, edition source, license, and detail page.
- `summary.json` — counts, scope, and catalog checksum.

## Boundary

This catalog establishes **symbolic score–MIDI provenance**. It does not assert that a separately recorded orchestra followed the edition, nor does it merge different movements into a single work-level count.
