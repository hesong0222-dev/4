# EnsembleSet chamber-ensemble score–MIDI–audio catalog

- Item-level records: **80**
- Mutopia-derived inputs: **71**
- RWC Classical-derived inputs: **9**
- Symbolic inputs: MIDI or MusicXML
- Rendered audio: BBC Symphony Orchestra sample library, 20 microphone/mix configurations
- Human-performance claim: **none**
- Access: restricted academic-use release

`manifest.csv` is a cleaned item-level export of the official EnsembleSet metadata sheet. It records source type, work, composer, instrumentation, license label, duration, and provenance class. One metadata row is explicitly named `unknown`; it is retained but marked as having unidentified source/rights.

These are chamber-ensemble and quartet/trio records, not all full symphonic conductor scores. They are therefore reported as a supplemental symbolic ensemble tier and are not added blindly to the canonical full-orchestra count.
