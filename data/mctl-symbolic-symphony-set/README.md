# S3 Symbolic Symphony Set score–MIDI catalog

- Complete symphonies: **4**
- Complete movements: **16**
- Composers: Mozart, Beethoven, Tchaikovsky, Dvořák
- Published score formats: PDF and MusicXML
- Prepackaged MIDI: **no**
- MIDI relation: deterministic export from the exact movement MusicXML

`manifest.csv` enumerates every movement in the repository and records the paired PDF/MusicXML paths plus a reproducible MIDI-export command. The 16 entries are high-quality full orchestral movement scores, but they are not added as independent human-recording matches.
