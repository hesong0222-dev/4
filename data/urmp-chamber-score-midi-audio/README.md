# URMP chamber score–MIDI–performance catalog

This directory enumerates all **44** official URMP piece labels:

- 11 duets
- 12 trios
- 14 quartets
- 7 quintets

Each piece provides a MIDI musical score, isolated human instrument recordings, an assembled ensemble mix/video, and frame-/note-level annotations. The players were recorded separately while following a shared conducting reference.

## Boundary

URMP is a chamber-ensemble corpus, not a full symphony-orchestra corpus. The supplied MIDI is a score reference; it is not represented here as an expressive performance MIDI or as proof that an independently printed edition was used. The 44 records are therefore kept in a supplemental real-performance tier and are not added to the canonical full-orchestra score count.
